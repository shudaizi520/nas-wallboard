# 实时网速的网络接口

在管理页的「桌面内容 → 实时网速 → NAS 网络接口」中选择网卡。选项来自当前采集的 TrueNAS reporting graph 标识，不会额外查询 NAS。

默认「自动」兼容已有配置。每次采样只取一个接口，按其接收与发送速率之和选择最高者；相同总量按接口标识排序决定。收发数据必须来自该接口同一条完整记录，单位由 TrueNAS 的 kilobit/s 转为 byte/s。

固定接口时，两项速率都必须可用。接口消失、只有一个方向有数据或采样过期时，网速显示「—」和异常色；不会改选其他接口，也不会补零。真实的零流量仍显示 `0 B/s`。已保存但不可用的接口会保留在下拉框，直到用户主动修改。没有任何完整网络样本时，仍沿用实时采集模块的不可用状态。

显示的是 NAS 接口自身的流量，不代表路由器或手机流量。桥接、聚合、VLAN 和虚拟接口可能统计同一流量的不同层级，自动模式不将它们求和。

若接口尚未出现在选项中，可选「手动输入接口标识」输入其 TrueNAS reporting graph identifier，例如 `eno1`、`br0` 或 `bond0`。物理与虚拟接口常见的字母、数字、点、下划线、冒号、`@` 和连字符均受支持；路径、空白和控制字符会被拒绝。接口标识只用于精确匹配采样，不参与文件路径或命令构建。

选择保存在既有 widget 配置中，随加密备份导出并随恢复保留。保存后立即应用到当前采样，无需重启采集；刷新频率仍为原来的五秒。接口列表沿用现有 reporting metadata 缓存；NAS 新增接口可能需要重新建立集成采集以重新加载元数据。
