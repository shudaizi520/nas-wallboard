第一步 · 兼容性

几分钟完成设置

之后所有功能都可以在网页里管理，不需要编辑 YAML，也不需要再找 Codex。当前版本专门支持 TrueNAS SCALE 25.10 及以上版本。

开始前准备
请在 TrueNAS 中创建一个专用的只读服务账户和 API Key。向导会逐项验证实际权限，不会把密钥显示在设置结果里。

第二步 · TrueNAS 访问

连接你的 TrueNAS

建议账户只授予读取系统、存储池、硬盘、网络、应用、告警和实时性能所需的权限。

检测到旧版配置
连接和密钥已经安全导入，不需要重新输入。下一步会重新验证权限。
当前页面使用 HTTP
首次提交的 API Key 会在你的局域网内以未加密方式传输。仅在可信 LAN 使用，或先配置 HTTPS 反向代理。

第三步 · 权限验证

连接测试

服务会真实调用运行时所需的每一种只读接口，避免安装完成后才发现缺少权限。

第四步 · 本地管理

创建管理员密码

这个密码只保护 NAS Wallboard 的管理页面，不会修改 TrueNAS 账户。会使用 Argon2id 加密保存。

第五步 · 自动发现

这些资源已经就绪

发现结果只用于生成合理的默认组件。你之后可以在管理页面随时调整显示内容和数据来源。

第六步 · 确认

可以开始了

保存时会再次测试连接，然后一次性写入管理员账户、TrueNAS 设置和密钥。失败不会留下半套配置。
